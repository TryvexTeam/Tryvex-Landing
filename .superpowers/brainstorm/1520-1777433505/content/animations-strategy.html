¿Cómo manejamos las animaciones?

El landing actual tiene 155 líneas de JS manual: IntersectionObserver, parallax, word-split, contadores, magnetic hover. Framer Motion reemplaza todo eso — la pregunta es cómo.

Lo que tenemos hoy vs. lo que propone Framer Motion

Hoy — JS vanilla
• IntersectionObserver global → clases CSS
• split(texto) manual en cada heading
• requestAnimationFrame para parallax
• setInterval para contadores
• mousemove listener para magnetic hover
• scrollY polling para navbar
Con Framer Motion
• whileInView → reemplaza IntersectionObserver
• staggerChildren → word-split declarativo
• useScroll + useTransform → parallax
• useMotionValue + animate → contadores
• whileHover → magnetic hover
• useScroll → navbar scroll state

Tres estrategias de adopción

Opción A — Conservadora
Mantener JS manual + Framer solo para lo nuevo
Migrar solo secciones nuevas. Las animaciones existentes siguen con IntersectionObserver + RAF.
✓ Menos trabajo inicial
✗ Dos sistemas en paralelo
✗ Bugs difíciles de debuggear
✗ Deuda técnica desde el día 1
Recomendada
Opción B — Reemplazo completo
Framer Motion para todo desde el inicio
// SectionWrapper universal
<motion.section
  initial={{ opacity:0, y:32 }}
  whileInView={{ opacity:1, y:0 }}
  viewport={{ once:true }}
  transition={{ duration:0.6,
    ease:[0.16,1,0.3,1] }}
/>
✓ Un solo sistema, sin conflictos
✓ useReducedMotion automático
✓ Stagger y orchestration declarativos
✓ Base limpia para animaciones futuras
Opción C — CSS puro
Solo CSS scroll-driven + transitions
CSS Scroll-Driven Animations API + @keyframes. Sin JS de animación.
✓ Bundle JS mínimo
✗ Safari soporte parcial aún
✗ Contadores y parallax requieren JS igual
✗ No escala a interacciones complejas

Las 6 animaciones del landing → equivalente en Framer Motion

Scroll reveal

whileInView en SectionWrapper. Variantes: fade-up, fade-left, scale-in según prop.

Word-split

AnimatedText con staggerChildren. Cada palabra es motion.span con delay incremental.

Parallax

useScroll + useTransform. El grain layer y blobs se mueven a velocidades distintas.

Contadores

useMotionValue + animate en Counter. Trigger al entrar en viewport, easing expo.

Magnetic hover

useMotionValue + spring en botones CTA. Sigue suavemente al cursor.

Navbar scroll

useScroll + useMotionValueEvent. Detecta dirección → muestra/oculta la pill glass con spring.
