Stack elegido: Next.js 15

La única opción que cubre todos los requisitos sin compromisos.

Por qué Next.js gana para Tryvex

Backend integrado

API Routes y Server Actions viven dentro del mismo proyecto. No necesita servidor aparte para conectar Stripe, MercadoPago, n8n o cualquier API de automatización de Tryvex.

Pasarela de pago

Stripe y MercadoPago tienen SDKs nativos para Next.js. Los webhooks se manejan con route.ts. Sin CORS manual ni servidor Express adicional.

Escalabilidad real

El landing de hoy se convierte en blog, portal de clientes o SaaS mañana — sin migrar de tecnología. Mismo repo, misma estructura.

SEO + Performance

SSG para páginas estáticas + SSR donde necesite datos dinámicos. Core Web Vitals excelentes + Metadata API nativa para SEO perfecto.

Stack completo propuesto

framework → Next.js 15 (App Router)
lenguaje → TypeScript
estilos → Tailwind CSS v4 + CSS Variables (sistema actual preservado)
animaciones → Framer Motion (reemplaza IntersectionObserver manual)
ui base → shadcn/ui (headless, sobre Radix UI)
validación → Zod (forms y APIs)
pagos → Stripe SDK (cuando se integre)
deploy → Vercel (zero-config)
tipografía → Geist + JetBrains Mono (ya las usan, se mantienen)

Por qué no los otros

Vite + React ✗

Sin backend nativo. Para integrar Stripe necesitaría un servidor Express separado — dos repos, doble complejidad de deploy.

Astro ✗

Excelente para performance estática, pero las islas React son para blogs — no para apps con pagos, formularios y autenticación futura.
