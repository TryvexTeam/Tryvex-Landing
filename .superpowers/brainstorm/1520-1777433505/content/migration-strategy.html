¿Cómo hacemos la migración?

Ya tenemos el stack. Ahora decidimos el orden de construcción — la diferencia entre tener algo live en días o en semanas.

Tres enfoques de migración

Opción A — Big Bang
Reescribir todo de una vez
Scaffoldear Next.js y migrar las 11 secciones + animaciones GSAP + estilos en una sola iteración antes de publicar algo.
Semana 1: scaffold + secciones
Semana 2: GSAP animations
Semana 3: polish + deploy
Sin nada live hasta semana 3
✓ Un solo esfuerzo continuo
✗ Semanas sin poder mostrar avance
✗ Bugs acumulados al final
Recomendada
Opción B — Por fases
Scaffold → secciones → animaciones
F1 → Next.js base + tokens
F2 → UI components compartidos
F3 → 11 secciones en React
F4 → GSAP + Framer animations
Deploy posible desde F3
✓ Cada fase es un hito visible
✓ Deploy posible desde fase 3
✓ Bugs aislados por sección
✓ Animaciones como capa separada
Opción C — Paralela
Landing viejo live, nuevo en desarrollo
El index.html vanilla sigue en producción. El nuevo Next.js se construye en rama separada sin presión de tiempo.
main → index.html vanilla (live)
feat/nextjs → nuevo proyecto
Swap cuando esté listo
✓ Sin presión de romper producción
✗ Dos codebases en paralelo
✗ Duplicación de trabajo de contenido

Opción B — Plan de fases detallado

F1
Scaffold base — 1 día
npx create-next-app + TypeScript + Tailwind v4 · Tokens CSS migrados a tokens.css · Tailwind config extendido con colores Tryvex · Fuentes via next/font · Layout raíz con metadata SEO
F2
UI components compartidos — 1 día
GlassCard · AnimatedText · Counter · SectionWrapper · Button · Estos bloques desbloquean la construcción de todas las secciones
F3
11 secciones en React — 2-3 días
Orden: Navbar → Footer → Hero → Services → Process → Metrics → Testimonial → Pricing → FAQ → LogoStrip → CTAFinal
Al terminar F3 el landing es deployable en Vercel — fidelidad visual completa, sin animaciones GSAP aún.
F4
GSAP + Framer animations — 2 días
Hero pinned scrub · SplitText headings · Parallax 3 capas · Process horizontal scrub · Métricas counter scrub · Pricing 3D tilt · Navbar scroll hide/show
🚀
Deploy Vercel — día 7-8
vercel --prod · Zero-config · CI/CD automático en cada push a main · Dominio tryvex.cl apuntado al proyecto

✅ Recomendación: Opción B — por fases. En 7-8 días el landing de Tryvex está vivo en Vercel con animaciones GSAP de nivel agencia premium. ¿Aprobamos este plan y pasamos a escribir el spec?
