¿Qué stack base usamos para Tryvex Landing?

Migrando de HTML/CSS/JS vanilla a React moderno. Tres caminos sólidos para una landing de agencia tech como Tryvex.

Next.js 15

Next.js 15 + App Router

El estándar de la industria para sitios que van a crecer. SSR/SSG para SEO perfecto, React Server Components, deploy en Vercel en 1 click. Ideal si el landing evoluciona a blog, casos de estudio o portal.

Pros

  • SEO nativo (SSR/SSG)
  • Escala a producto completo
  • Deploy instantáneo Vercel
  • Ecosistema enorme

Contras

  • Más config inicial
  • Algo overkill para 1 página
Vite + React

Vite + React 19

Setup mínimo, velocidad máxima. SPA pura sin servidor ni hidratación compleja. Control total sin opiniones de framework. Ideal para iterar rápido sobre el diseño.

Pros

  • Setup en 2 minutos
  • Dev server ultrarrápido (HMR)
  • Sin opiniones impuestas
  • Curva suave

Contras

  • SEO manual (sin SSR)
  • Deploy menos integrado
Astro 5

Astro 5 + React Islands

Mejor performance para sites de contenido. HTML estático por defecto — solo los componentes interactivos cargan React. Bundle mínimo, Core Web Vitals perfectos de entrada.

Pros

  • Performance top tier
  • 0 JS por defecto
  • CWV excelentes
  • MDX + blog nativo

Contras

  • Menos familiar que Next
  • Mental model de "islas" nuevo

💡 Recomendación Jarvis: Next.js 15 — Tryvex es una agencia que va a crecer. El landing de hoy puede ser el portal con blog, casos de estudio y dashboard mañana.
