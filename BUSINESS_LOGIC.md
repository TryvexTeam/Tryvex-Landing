# Tryvex Landing — Business Logic

## Qué es Tryvex

Software studio en Santiago, Chile. Construye automatizaciones, landing pages y SaaS a medida para negocios que quieren escalar sin contratar más personas.

## Servicios

| Servicio | Descripción | Precio base |
|----------|-------------|-------------|
| Automatización | Flujos n8n/Zapier, integraciones SII/WhatsApp | — |
| Landing pages | Diseño + copy + dev en una semana | desde $1.8M CLP |
| SaaS a medida | MVPs 4–8 semanas, Next.js + Postgres | — |
| Tryvex partner | Equipo dedicado mensual | $2.4M CLP/mes |

## Usuario Target

Negocios chilenos de 2–30 personas que usan planillas para procesos que podrían automatizarse. Pain principal: tiempo perdido en tareas manuales repetitivas.

## Propuesta de Valor

"Automatizamos lo aburrido. Tú vendes lo importante."

## Identidad Visual

- **Colores**: Dark (#0e0e0e base) con acento rojo (#e53935)

- Next.js + TypeScript (App Router)
- GSAP ScrollTrigger — animaciones scroll
- Anime.js v4 — animaciones de escenas
- Lenis — smooth scroll
- CSS custom (no Tailwind para componentes de landing)
